# Madhav Ecommerce Sales Dashboard 📊

An interactive Power BI dashboard designed to analyze ecommerce sales performance, profitability, product categories, customer purchasing patterns, and regional sales across India.

This project transforms raw ecommerce data into meaningful visual insights to support better business decisions.

## 📸 Dashboard Preview

![Madhav Ecommerce Sales Dashboard](images/dashboard.png)

## 🎯 Project Objectives

- Analyze overall sales, profit, quantity, and average order value.
- Identify top-performing states and product sub-categories.
- Understand customer payment preferences.
- Track monthly profit trends and seasonal performance.
- Explore sales performance using interactive quarterly and state filters.

## ✨ Key Features

- **KPI Cards:** Total Amount, Total Profit, Total Quantity, and Average Order Value (AOV).
- **State-wise Analysis:** Compare sales performance across different states.
- **Category Analysis:** Understand quantity distribution across product categories.
- **Payment Mode Analysis:** Compare payment preferences, including COD, UPI, credit cards, debit cards, and EMI.
- **Monthly Profit Trends:** Identify profitable and loss-making months.
- **Sub-category Analysis:** Compare profit across products such as printers, bookcases, sarees, accessories, and tables.
- **Interactive Filters:** Explore data by quarter and state.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query for data cleaning and transformation
- DAX for measures and calculations
- Data visualization and interactive reporting

## 📊 Key Business Metrics

| Metric | Description |
|---|---|
| Total Amount | Overall sales amount |
| Total Profit | Profit generated from sales |
| Total Quantity | Total quantity of products sold |
| Average Order Value (AOV) | Average sales value per order |
